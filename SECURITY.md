# Security & Acceptable Use

`ness-attack` is an offensive-security lab container intended for **authorized
self-testing only** — systems you own or have explicit, documented permission
to test.

## Acceptable use
- Testing your own PrivateNess nodes, services, and infrastructure.
- Lab and CTF environments you control.
- Authorized engagements with written scope.

## Not acceptable
- Any system you do not own or lack written authorization to test.
- Using the tooling to cause damage, exfiltrate data, or disrupt service.

The maintainers provide this software with no warranty and accept no liability
for misuse. Running these tools against third-party systems without
authorization is likely a crime in your jurisdiction.

## Reporting
Found a vulnerability in this project (not in a target)? Open a private
security advisory on the repository, or contact the maintainer directly.
